# ThinkRail Native 多 Agent 设计包

状态：现行设计，2026-10-30 改写。取代 2026-10-29 版“GPUI 客户端 + Bun 业务宿主 + SDK worker”方案；旧方案的决策不再有效。

交付目标：Windows 优先的纯 Rust / GPUI 原生 ThinkRail，界面对标原版 ThinkRail，用户可在设置中选择 pi、OMP 或 DSH 作为 Agent。本项目是独立仓库，不修改原 ThinkRail 仓库及其 Web/CLI。

1. [调研](01-research.md)：已核实的事实、实测结果与限制。

## 已确认的用户决定

| 编号 | 决定 | 落点 |
|---|---|---|
| U01 | 独立项目 `thinkrail-native`，不在原 ThinkRail 仓库改造 | 全部 |
| U02 | 业务全部用 Rust 实现，不保留自有 TS/Bun 后台 | 03 §1、04 §2 |
| U03 | 所有技术栈尽量用最新正式版并精确锁定 | 02 §3、04 §10 |
| U04 | UI 对标原版 ThinkRail（布局、配色、尺寸、交互），不自行发挥 | 04 §9 |
| U05 | 面向接口、模块化、组件化，日志和异常有规范，遵循 Rust 与 GPUI 最佳实践 | 03 §2、04 §1–3、§9 |
| U06 | 已装的引擎直接用（编码搭档自动检测 `PATH`）；没装时“设置 → 编码搭档”提供一键安装，方便用户管理（同 Cherry Studio）：下载固定版本、按 SHA-256 校验的 Node / Bun，再把固定版本的引擎包装到数据目录。应用安装包本身不带引擎（2026-11-01 用户确认，取代原“不内置、不下载”）。2026-11-01 起不再支持在 Agent 档案里手填可执行文件，档案整体取消，见 [agent-settings 07](../agent-settings/07-default-agent.md) | 04 §4；agent-settings 04 §7.10、07 |
| U07 | 不导入原 ThinkRail（`~/.thinkrail`）旧数据，数据目录独立 | 04 §7 |
| U08 | Agent 需要能直接调用宿主 TODO / 审查工具 | 04 §6 |
| U09 | 用户主要在 Windows 使用 | 01 §4、05 |
